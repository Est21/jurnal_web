Statik site (HTML + CSS + küçük bir JS), derleme yok, harici istek yok.

- `index.html`, `privacy.html` — Türkçe; `en/` — İngilizce
- Ekran görüntüleri: `assets/screens/` içine şu adlarla koy: `desktop-home.png`, `desktop-editor.png`, `desktop-board.png`, `desktop-library.png`, `desktop-lock.png` (16:10), `mobile-home.png` (9:19)

- Yayın: GitHub Pages (Settings → Pages → main / root)
